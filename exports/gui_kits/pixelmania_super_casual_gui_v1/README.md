# PixelMania Super Casual GUI Kit v1

Original glossy casual UI PNGs made for PixelMania. These are not copied from the LayerLab pack; they are custom assets in the same broad mobile-casual UI genre.

## Update

This version restores the first-pass visual style and only fixes the sharp/squared inner corners by using cleaner rounded masks.

## What is included

- Drop-in-sized PNGs matching the current `Assets/ui/inventory` asset dimensions.
- Panels/windows/popups/cards/header/footer/hotbar/input/tabs/slots/buttons.
- Extra green/red/yellow pressed/hover button states beyond the current folder.
- Preview sheet in `preview/pixelmania_super_casual_gui_preview.png`.

## Godot notes

These are plain transparent PNGs. Godot will generate `.import` files when the folder is added to the project.

Suggested `StyleBoxTexture` margins:

- Large/medium panels: 28 to 32 px
- Small panels/cards/tooltips: 20 to 24 px
- Buttons/tabs: 18 to 22 px
- Slots: 24 px

No game scripts, scenes, or existing assets were changed by this export.
