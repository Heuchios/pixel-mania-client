How to read the drops

0–3 blocks: 25% each for 0, 1, 2, or 3. 0–1 seeds: 50% each for 0 or 1. Independent rolls apply to breaks and harvests wherever specified. Wagon Wheel uses 0–6 blocks and 0–3 seeds.

Gems are averages per block broken. Break XP follows clear numeric sheet values. Tree gems, tree XP, and growth times retain their previous rules. Blank/dash cells and conflicting values are flagged.

Uniform 0–3 drops average 1.5 blocks per break, so repeated replacement and breaking can grow supply. A finite complete-recycling yield does not apply. Sugarcane uses the user-confirmed 2.2 gems per break.
