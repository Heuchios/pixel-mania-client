PixelMania farming guide

All 332 blocks and placed states. Read each reward as chance → amount. For example, 30% → 1–3 blocks means a 30% chance to receive 1, 2, or 3 blocks, otherwise none.

A complete farming cycle returns 1.05–1.10 seeds on average after harvesting and repeatedly breaking all returned blocks. Keep one seed to replant. Individual trees can return fewer seeds.

Gem amounts are long-run averages, not guaranteed totals. Times start when a seed is planted. Existing trees keep their saved timers. Click a block name for exact rolls, exceptions, and source notes.

Water has no plantable tree or bucket rewards. Recoverable utilities do not generate repeatable gems. Equipment bonuses, event tickets, machine production, and XP are excluded.
