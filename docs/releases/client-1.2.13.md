# PixelMania 1.2.13

- Lucifer, Susanoo, and Dev Wings now use the shared wing atlas with separate inventory previews.
- Lucifer's jump animation plays 1-2-3-2-1. Dev Wings retains the faster 1-2-3-4-3-2-1 sequence.
- Adds the Police Shirt, Pants, and Hat, Flaming Skull, and the rare Octopus Hat fishing reward.
- Updates player walk, jump, fall, and placement poses and shows the selected placeable item in hand.
- Includes refreshed item artwork and the corrected hand-item atlas.

Existing wing item IDs, ownership, jump abilities, and trade restrictions are preserved.
The desktop release is 1.2.13. Android build version is 1.2.13 (code 35); its live minimum version must remain unchanged until Play rollout is verified.

Release validation includes atlas bounds, wing previews and animation sequences, player pose transitions, selected hand previews, hotbar refresh, backend item parity and security checks, and staging/production health and launcher checks.
